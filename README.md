# Desktop Tools

A modular, customizable desktop tools app for Windows: one engine, many tools, shown as compact cards in a
control center (and later a top bar, dock and launcher).

**Status:** design phase. See [docs/CONCEPT.md](docs/CONCEPT.md) and [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
Contributors (human or AI): start with [AGENTS.md](AGENTS.md).
